The Income-Expense Organizer Application is a powerful financial management tool designed to help users efficiently track their income, expenses, and overall financial health. Built with Spring Boot and MySQL, the application provides a seamless and user-friendly experience for managing personal and business finances.

## Key Features:

✅ Add, Edit & Delete Transactions – Easily record and manage your income and expense entries.
✅ Financial Summaries – Get insights into total income, total expenses, balance, and maximum/minimum transactions at a glance.
✅ Graphical Visualizations – View interactive charts and graphs to analyze spending patterns.
✅ Category Management – Organize transactions into customizable categories for better financial tracking.
✅ Secure Data Handling – Robust backend built with Spring Boot & Hibernate JPA, ensuring data security and efficiency.
✅ Docker Integration – Deploy with ease using Docker containers for a seamless setup.

## Tech Stack:
🔹 Backend: Spring Boot, Hibernate JPA, MySQL
🔹 Frontend: Angular
🔹 Database: MySQL (running in Docker)
🔹 Deployment: Docker, Spring Boot

### Clone the Repository

```bash
git clone https://github.com/SachithRangana1/Income-Expense-Organizer-Application.git
```

## Open the application by IDE
##

### Run below command in your terminal
```bash
docker-compose up
```

### Build the application using maven
##### Run below code in your terminal
```bash
mvn clean install
```

### Run the Spring boot Application
##### Run below code in your terminal
```bash
mvn spring-boot:run
```
